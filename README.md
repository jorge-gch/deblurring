# Deblurring

Project aimed at exploring and applying image restoration techniques focused on deblurring. The primary work is contained within a Jupyter Notebook, designed for experimenting with filters, image enhancement algorithms, and result visualization.

## Description

This repository is designed to work with blurry images and apply methods to help recover details and enhance visual sharpness. The main objective is to study and test digital image processing techniques to reduce the blur effect and identify the most suitable results based on the image type.

## Objectives

- Improve the visual quality of blurry images.
- Explore image processing methods to recover details.
- Document the project's workflow in a reproducible format.
- Facilitate testing and experimentation with different techniques.
